# Student Accommodation Management System

## Project Overview

The **Student Accommodation Management System** is a cloud-based application designed to simplify the management of student rental properties. It provides landlords with a centralized platform to manage accommodation listings, room availability, student applications, and maintenance requests.

Students can use the system to browse available accommodation, view rental details, submit applications, and track their application status.

## OPC Persona

The proposed OPC will be an independent landlord running 5 student rental properties. Landlord is someone who arranges accommodation for college and university students and takes care of the rental list, room availability, application and information for tenants, and maintenance requests.

Currently, most of the activities are conducted manually by the landlord using phone calls, text messages, spreadsheets and emails. This makes it hard to keep information coherent and answer student questions in a timely manner.

## Business Pain Point

"I manage five student rental units, and keeping track of everything is becoming difficult. Students contact me through different channels to ask about room availability, submit rental inquiries, and report maintenance issues. I spend too much time searching for information and sometimes miss important requests. I need one centralized place where I can manage my properties, student applications, and maintenance requests."

## User Roles

The system will support two primary user roles:

### 1. Landlord (Owner)

* Create, update, and manage accommodation listings.
* Add room details, rental prices, and availability.
* View and manage student applications.
* Review applications and update their status.
* View and manage maintenance requests.

### 2. Student (Tenant)

* Register and log in to the application.
* Browse available student accommodation.
* View room details, rental prices, and availability.
* Submit rental applications.
* Track application status.
* Submit maintenance requests.

## Proposed Solution

We suggest creating a Student Accommodation Management System, an application that will be cloud-based and will enable the landlords to manage the student housing and help the students find accommodation and apply for rent in one place.

## Success Measures

The project will be considered successful when:

* The landlord can create and manage listings for five rental units.
* Students can register and log in successfully.
* Students can browse available accommodation and view rental details.
* Students can submit rental applications online.
* The landlord can review applications and update their status.
* Students can submit maintenance requests.
* User information is stored securely, with access based on user roles.

## Cloud Platform

**Selected Platform: Amazon Web Services (AWS)**

Our team plans to develop and test the application using the AWS Academy Learner Lab environment.

Potential AWS services include:

| AWS Service                 | Intended Purpose                 |
| --------------------------- | -------------------------------- |
| Amazon EC2                  | Application hosting              |
| Amazon RDS                  | Relational database              |
| Amazon S3                   | Property images and file storage |
| Amazon Cognito              | User authentication              |
| Amazon CloudWatch           | Application monitoring           |
| AWS IAM and Security Groups | Access control and security      |

The final services will depend on project requirements and the permissions available in the Learner Lab environment.

## Why Cloud?

We decided to use a cloud-based solution to enable the landlord and students to access the app from different locations, and not rely on a single computer. Centralized data storage, authentication, scalability, availability and monitoring can be achieved through cloud services. By doing this, the application can expand should a landlord have other rental properties in the future.

## Project Goals

Our main goals are to:
